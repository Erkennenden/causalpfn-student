# V3 无 IV 版

本版删除了上一版的 IV 相加分支及 `_upstream_iv.py`。当前 DGP 保留三种结果函数构造形式，不加入 U。

令 c_i = (X_i, 邻居 X 的均值)，z_i = (c_i, t, e)。每个任务以各 1/3 的概率抽取一种形式，再抽取网络结构、权重和偏置：

| 名称 | f 的形式 | 原代码来源 |
|---|---|---|
| `standard` | 稀疏 MLP(z) | `standard.py:OutcomeGenerator` |
| `dense` | 全连接 MLP(z) | `base.py:BaseMLPGenerator` |
| `composition` | g(c, h(z)) | `frontdoor.py:MediatorGenerator` 与 `OutcomeGeneratorWithMediator` 的网络生成器 |

各 1/3 是本项目的默认混合比例，不是 CausalFM 论文给定的配比。有限任务集合中数量不保证完全相等。`additive` 已不再是有效选项。

复合形式中的 h 是 f 内部的确定性计算，不生成数据中的中介变量，不引入 front-door 因果假设。每个任务只抽一套网络；该任务全部节点、观测结果、反事实计算都使用它。

## 保留的数学设定

Y_i(t,e) = f_theta(X_i, mean_neighbor_X_i, t, e) + epsilon_i。

- 固定 ER 图：N=1000、p=0.02、seed=12345，使用原保存文件。
- X~N(0,1)，T~Bernoulli(0.5)，邻居协变量和暴露均取邻居均值。
- epsilon~N(0,4²)，只进入观测 Y；f 内部无随机节点噪声。
- 原类仍抽取节点噪声分布，以保留参数抽样顺序，但向量化求值使用零内部噪声。
- S=1{K>floor(d/2)}；逐点计算 f(c,t,k/d)，再按条件二项权重精确聚合 mu_i(t,s)。
- 监督目标仍是 mu00、mu10、mu11 三个 CEPO。
- direct=mu10-mu00；spillover=mu11-mu10；total=mu11-mu00；ATE 为节点平均。

Transformer、embedding、聚合公式、基线方法和训练规模沿用上一版。

## f 的随机网络配置

standard、dense 与 composition 外层：总层数 3–5，宽度 10–24。composition 内层沿用原版 factual mediator 配置：总层数 3–4，宽度 10–24。总层数包含输入和输出层。

所有网络权重/偏置为 N(0,1)，隐藏层 tanh，输出线性。稀疏网络保留原始 edge_drop_prob=0.4 实现：先抽候选删除边，指向输出节点的边仍保留，实际删除比例未必恰为 40%。剩余三个形式在指定相同种子和指定 family 时保持上一版的函数数值；默认 mixture 改为三选一后，任务对应的 family 可能改变。

## 运行

原来的主训练命令已接入三种形式的混合：

```bash
PFN_CONTAINER=musacode bash launch_causalfm_docker.sh
```

默认仍为 8 卡、40960 训练任务、5120 验证任务、125 epoch。没有增加训练量，也无需先运行 scaling sweep。

只查看 DGP 样例：

```bash
python -m causalfm_dgp_v1.demo --tasks 8 --output runs/v3_no_iv_preview
python -m causalfm_dgp_v1.demo --family composition --tasks 1 --output runs/v3_no_iv_composition
```

`--family` 可选 `mixture`、`standard`、`dense`、`composition`。输出 `nodes.csv`、`batch.pt`、`mechanisms.json`；后者保存每个任务的实际形式、参数及输入说明。

可选短训练自检：

```bash
python -m scaling_v2 smoke --device musa --output runs/v3_no_iv_first_try
```

该命令只做 20 次更新。CPU 本地可将 musa 改成 cpu。

使用新的解压目录和输出目录。数据指纹和训练版本已更新，旧版四种形式生成的缓存与 checkpoint 不会被用于本版的续训。包名 `causalfm_dgp_v1` 保留以兼容导入；内部版本为 `causalfm_network_cepo_v3_no_iv`。
