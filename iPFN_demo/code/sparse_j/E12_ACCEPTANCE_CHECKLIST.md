## 当前必须如实说明的失败

溢出主系数加倍条件下，原 J 的溢出覆盖率 75.46%，正确条件先验的模拟 oracle 为 93.52%。这与“模型在变强的溢出机制下仍使用原先验/表征，可能收缩过强”的解释相符，但 oracle 同时知道真表征和先验，**这不是单独证明先验导致失败的消融**。直接主系数加倍时溢出覆盖为 89.81%，也没有达到 90%。均不能因原主测试达标而删掉。

现有校准只针对原参考分布；本次没有把旧系数宣称适用于偏移条件，也没有用已看过的筛查真值调宽区间。若继续研究提高偏移覆盖率，先把此次 4000–4011 当作开发诊断，另行预注册覆盖偏移范围的开发/校准/最终测试机制，比较先验敏感性或分布匹配的独立区间校准，同时报告区间宽度、bias 和 RMSE。最终测试只能用于评价，不能循环用于挑参数。
