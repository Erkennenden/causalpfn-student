# E1.2 baseline 信息与目标核对（供 E3 交接）

核对指定论文中与输入、假设、估计目标直接相关的章节；这里没有声称完成三篇论文的复现。当前已有冻结 J、HT/Hajek、回归与图核方法的共同评测。J 是仓库现有方法，不能改名为官方 CausalPFN；kernel-new 也不是 HyperSCI。

| 文献 | 输入、假设与目标 | 对当前四状态目标的适配判断 |
|---|---|---|
| Ma 等，HyperSCI | 输入超图结构、节点特征、处理和结果；用表示汇总干扰环境，并假定观察特征足以控制相应混杂；在干扰下估计个体处理效应 | 当前是普通图，可考虑二元超边表达，但必须核对其自身处理效应如何对应当前 majority exposure 条件平均，不能直接视为等价；还需适配只观察部分节点 Y、固定 node_ids、四状态查询和支持标记 |
| CausalPFN | 给定 i.i.d. 观测 X,T,Y，在无混杂和 positivity 等强可忽略性假设下估计潜在结果条件均值、CATE/ATE；实现面向二元处理 | 当前网络节点相关且目标涉及自身处理和邻居暴露；直接喂入二元 T 不能宣称估计同一四状态目标。需明确网络依赖、暴露与识别适配；不把未运行的官方 checkpoint 写入结果 |
| 原始 TabPFN | 小型表格分类；基于合成先验的预测方法，论文明确其任务不是直接因果推断 | 不能把分类概率直接当作本项目干扰下的结果均值或 ATE；需要适配连续 outcome、四状态查询及识别设计，并重新验证 |

原文依据：[HyperSCI（任务定义与假设）](https://arxiv.org/html/2207.04049v1)、[CausalPFN（第 2、4、7 节）](https://arxiv.org/html/2506.07918v2)、[TabPFN（第 4.3 节）](https://arxiv.org/html/2207.01848v6)。表格最后一列是针对本项目的适配判断，不是论文作者已给出的兼容声明。

当前主表中 HT 为简单设计基线；kernel-new 为使用图/暴露信息的 outcome 基线；oracle-known-dgp 是模拟诊断上界参照，知道真隐藏表征、系数先验和噪声，仅使用观测 Y 拟合，**不使用真系数拟合**。Oracle 不是绝对性能上界保证，也不替代 E3 的文献复现。HT 没有逐节点 mu/ITE 或原接口 95% 区间时，相应项保留不支持。
