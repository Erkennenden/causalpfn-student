# E1.2 简要说明：Configuration 图结构拓展与独立区间校准

## 图结构与参数

在保留原 WS/ER/SBM 场景（base 0–7 及原冻结模型不变）的前提下，追加六种可复现的 Configuration 配置：

- 节点数 N=200（主实验），补充 N=50/100
- 平均度 4/8 × 度分布离散系数 CV 0/0.25/0.5（degree_spread 0/1/2 与 0/2/4）
- 简单无向连通图，有限步保度交换采样，记录实际度统计与图哈希
- 追加 base 8–13、family 100–105，独立 E1.2 入口，不覆盖原实验身份

## 检查方法（验证与隔离）

- 独立校准：每配置 100 个校准机制（ID 2000–2099）+ 200 个测试机制（ID 3000–3199），测试机制 3 次重复，共 10,800 测试上下文、86,400 方法执行记录
- 校准分数取 100 个中的第 96 分位、下限为 1；54 个系数在生成测试数据前冻结，测试真值不进入模型或调参
- 同测试上下文重跑原 J / HT / Hajek / F-z2 / Lin-z2 / kernel-old / kernel-new + 校准 J，并补充已知 DGP 的 oracle 对照
- 58 项测试通过；1,200 张测试图全部连通；10,800 对预测逐数组一致

## 结果

1. **覆盖率（95% 区间实际覆盖 ≥90%）**：主测试原 J 与校准 J 均 54/54 格达标，最低 93.33%。校准系数 42 个为 1、12 个扩宽，平均宽度比例 1.01377、最大 1.17570。
2. **与 baseline 比较（观测 50、六配置汇总）**：J / 校准 J 的 ATE RMSE 直接 0.26164、溢出 0.18325、总效应 0.31884，在完整支持的方法中三项均最小；绝对条件 bias 0.14873 / 0.12676 / 0.18918。
3. **已知限制（如实保留）**：机制偏移筛查中，溢出主系数加倍时原 J 溢出覆盖降至 75.46%、直接主系数加倍时 89.81%，未达 90%，作为已知失败保留，未用测试结果调参。

## 结论

Configuration 主实验达到 90% 覆盖目标；独立校准仅作为稳健性对照。建议保留冻结 J 为主结果、校准 J 为区间对照，并如实报告机制偏移下的覆盖失败。
